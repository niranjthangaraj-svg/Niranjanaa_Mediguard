# MEDIGUARD – SMART MEDICINE REMINDER AND AUTOMATED DISPENSER

## Project Description

1. MediGuard is an intelligent medicine reminder and automated dispensing system designed to improve medication adherence.
2. The project aims to help people take their medicines at the correct time and in the prescribed quantity.
3. It is especially useful for elderly people, patients with chronic illnesses, and individuals who follow multiple medication schedules.
4. Managing medicines manually can sometimes lead to missed doses, incorrect timings, or accidental repeated consumption.
5. MediGuard addresses these challenges through automation, monitoring, and timely notifications.
6. The system combines embedded technology, automation, sensors, and artificial intelligence.
7. It provides a convenient and user-friendly approach to everyday medication management.
8. The primary objective is to reduce medication errors caused by forgetfulness and improper medicine handling.
9. The device is designed as a compact and portable medicine dispenser.
10. Its physical structure consists of three layers that accommodate the medicine storage and dispensing mechanism.

## System Architecture and Design

11. The MediGuard device is designed with a compact cylindrical structure.
12. It consists of three separate layers for organized medicine storage and dispensing.
13. Each compartment is assigned to a particular medicine or scheduled dose.
14. The compartments are arranged to make medicine loading and maintenance easier.
15. An automated locking mechanism controls access to the medicine compartments.
16. The locking mechanism prevents unauthorized or premature access to scheduled doses.
17. The system uses a motor-based mechanism to control the dispensing operation.
18. A single motor is intended to operate the dispensing mechanism efficiently.
19. The motor rotates according to the programmed schedule.
20. The design focuses on minimizing mechanical complexity and power consumption.

## Smart Medicine Reminder System

21. The reminder system is one of the major features of MediGuard.
22. It maintains the medication schedule according to the user's prescribed timings.
23. The system continuously monitors the internal clock to identify scheduled medication times.
24. When the scheduled time arrives, the device activates the reminder mechanism.
25. A buzzer produces an audible alert to notify the user.
26. The notification reminds the user that a medicine dose is due.
27. The corresponding medicine compartment is identified based on the stored schedule.
28. The automated mechanism then enables access to the appropriate compartment.
29. The system is designed to prevent access to medicines outside their scheduled time.
30. This feature helps establish a consistent medication routine.

## Automated Dispensing Mechanism

31. MediGuard incorporates an automated medicine dispensing mechanism.
32. The mechanism operates according to the programmed medication schedule.
33. The motor controls the movement required to position the selected compartment.
34. The system is designed to release only the scheduled medicine compartment.
35. The locking mechanism provides controlled access to the selected dose.
36. The dispensing process reduces the need for manual medicine selection.
37. The mechanism is intended to simplify medicine handling for users.
38. The device aims to minimize accidental access to other stored medicines.
39. The dispensing operation is controlled through an embedded controller.
40. The overall mechanism combines hardware and software for reliable operation.

## AI-Based Prescription Recognition

41. MediGuard introduces an artificial intelligence-based prescription recognition feature.
42. This feature aims to simplify the process of entering medication details.
43. The user or caretaker can provide a prescription image to the system.
44. The AI module analyzes the uploaded prescription.
45. Optical character recognition techniques can extract relevant text from the prescription.
46. The extracted information is processed to identify medicine names and dosage instructions.
47. The system interprets available medication timing information.
48. The identified details are converted into a structured medication schedule.
49. The generated schedule can be reviewed and verified by the user or caretaker.
50. Once confirmed, the schedule can be transferred to the device controller.

## Caretaker Notification System

51. MediGuard includes a caretaker notification feature for additional support.
52. This feature helps family members or caregivers remain informed about medication-related events.
53. The system is designed to send SMS notifications to a registered caretaker.
54. Notifications can be generated when a scheduled dose requires attention.
55. The system can also provide alerts when a medicine dose is not acknowledged.
56. This helps caregivers monitor the medication routine remotely.
57. The caretaker can receive important updates without continuously checking the device.
58. The notification feature improves communication between patients and caregivers.
59. It provides an additional layer of supervision for individuals requiring assistance.
60. The system aims to make medication management more transparent.

## Low-Medicine Level Detection

61. Another important feature of MediGuard is low-medicine level monitoring.
62. The system aims to identify when the stored medicine quantity becomes insufficient.
63. A suitable sensing mechanism can monitor the medicine storage compartments.
64. When the quantity reaches a predefined threshold, the system generates an alert.
65. The low-medicine alert informs the user or caretaker about the need for refilling.
66. This feature helps prevent unexpected medicine shortages.
67. It supports better planning for medicine purchases and refilling.
68. The monitoring mechanism improves the overall usability of the dispenser.
69. It reduces the need for frequent manual inspection of medicine compartments.
70. The feature contributes to more organized medication management.

## Working Principle

72. The medication schedule is configured based on the verified prescription.
73. The medicines are placed in their assigned compartments.
74. The embedded controller stores and follows the configured schedule.
75. The system continuously checks the current time.
76. When a scheduled medication time is reached, the buzzer activates.
77. The motor-driven mechanism positions the corresponding medicine compartment.
